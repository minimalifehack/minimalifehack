# MINIMAL LIFEHACK

「毎日を、少しだけ軽く。」をテーマにしたWebアプリ紹介サイトです。

HTML・CSS・JavaScriptで構成されており、パッケージのインストールやビルドは不要です。

## ファイル構成

- `index.html` — ページの文章と構造
- `styles.css` — デザインとスマートフォン向けの表示設定
- `app.js` — ページ内リンクのスクロール処理
- `assets/minimal-lifehack-logo.jpeg` — ロゴ画像

## 手元で確認する

`index.html`をブラウザーで開いて確認できます。

Python 3がある場合は、このフォルダーで次のコマンドを実行して確認することもできます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000` を開きます。終了するにはターミナルで `Ctrl+C` を押します。

## 現在の内容

APP 01は「最初のアプリを準備中」、APP 02・03は公開予定の表示です。このフォルダーにアプリ本体は含まれません。

## GitHubへの保存

このフォルダーのファイル一式をリポジトリ（GitHub上の保存先）に保存します。
`index.html`はリポジトリの最上位に置く構成です。

GitHubへの保存と、Webサイトとしての公開は別の作業です。公開先・公開範囲を確認したうえで設定してください。

## 元のZIPからの整理

元のZIP内の`dist/`の内容を最上位に配置しています。サイト本体のコードと画像は変更していません。
元のホスティングサービス専用の`.openai/hosting.json`は、この保存用セットには含めていません。
