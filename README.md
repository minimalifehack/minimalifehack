# minimalifehack

「少なく、軽く。自分らしく。」をテーマにしたミニマリズムの情報サイトです。ブログを中心に、暮らしを助けるアプリも紹介します。

HTML・CSS・JavaScriptで構成されており、パッケージのインストールやビルドは不要です。

## ファイル構成

- `index.html` — ページの文章と構造
- `styles.css` — デザインとスマートフォン向けの表示設定
- `app.js` — ページ内リンクのスクロール処理
- `assets/minimal-lifehack-logo.jpeg` — ヘッダーロゴ
- `assets/minimal-lifehack-footer-logo.jpg` — フッターロゴ
- `assets/minimalism-quiet-living.jpg` — トップのイメージ写真（AI生成）

## 手元で確認する

`index.html`をブラウザーで開いて確認できます。

Python 3がある場合は、このフォルダーで次のコマンドを実行して確認することもできます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000` を開きます。終了するにはターミナルで `Ctrl+C` を押します。

## 現在の内容

アプリ紹介欄は「最初のアプリを準備中」の1枠です。このフォルダーにアプリ本体は含まれません。

BLOGはAPPSより上に配置しています。カテゴリーは「暮らしを整える」「ミニマル思考」「ミニマムライフコスト」「AI・便利ツール」「ミニマルなモノ」の5つです。
「小さな習慣」は「暮らしを整える」に、「デジタル整理」は「AI・便利ツール」に含めています。「ミニマル思考」では書籍などを通じたミニマルな考え方を扱います。
各カテゴリーは記事未公開のため「記事を準備中」と表示します。記事本文や投稿管理画面はまだ含みません。

記事を追加するときは、`index.html`の該当カテゴリー内にある`blog-articles`に記事へのリンクを配置し、`blog-empty`の準備中表示を置き換えます。カテゴリー名・説明も同じHTMLで編集できます。

## GitHubへの保存

このフォルダーのファイル一式をリポジトリ（GitHub上の保存先）に保存します。
`index.html`はリポジトリの最上位に置く構成です。

GitHubへの保存と、Webサイトとしての公開は別の作業です。公開先・公開範囲を確認したうえで設定してください。

## 元のZIPからの整理

元のZIP内の`dist/`の内容を最上位に配置しています。その後、ブログ掲載枠の追加、フッターロゴの差し替え、ミニマリズムを中心としたトップの再構成を行っています。
元のホスティングサービス専用の`.openai/hosting.json`は、この保存用セットには含めていません。
