# minimalifehack

「ミニマリズムで、好きなことと向き合う時間を増やす」をテーマにした情報サイトです。選択と集中を軸に、大切なことに時間や気持ちを注ぐためのヒントを発信します。ブログを中心に、暮らしを助けるアプリも紹介します。

HTML・CSS・JavaScriptで構成されており、パッケージのインストールやビルドは不要です。

## ファイル構成

- `index.html` — トップページ、カテゴリー別の記事一覧、更新情報
- `articles/*.html` — 各カテゴリーの入門記事5本
- `styles.css` — デザインとスマートフォン向けの表示設定
- `app.js` — メニューの開閉と記事・RSSのURLコピー（ページ内移動はブラウザー標準）
- `analytics.js` — Google アナリティクスの設定と閲覧者の選択
- `about.html` — 運営概要とサイトの方針
- `contact.html` — お問い合わせ窓口（Googleフォーム公開待ち）
- `privacy.html` — プライバシーポリシーとアクセス解析設定変更への導線
- `feed.xml` — 記事更新を購読するためのRSS
- `sitemap.xml` — 検索エンジン向けのページ一覧
- `EDITORIAL.md` — カテゴリー別の執筆ルール案と公開前チェック
- `assets/minimal-lifehack-logo.jpeg` — ヘッダーロゴ
- `assets/minimal-lifehack-footer-logo.jpg` — 旧フッターロゴ（現在未使用）
- `assets/minimalism-quiet-living.jpg` — トップのイメージ写真（AI生成）
- `assets/editorial-*.jpg` — 記事カテゴリー用のイメージ写真4点（AI生成）

## 手元で確認する

`index.html`をブラウザーで開いて確認できます。

Python 3がある場合は、このフォルダーで次のコマンドを実行して確認することもできます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000` を開きます。終了するにはターミナルで `Ctrl+C` を押します。

## 現在の内容

アプリ紹介欄は「最初のアプリを準備中」の1枠です。このフォルダーにアプリ本体は含まれません。

BLOGはAPPSより上に配置しています。カテゴリーは「暮らしを整える」「ミニマル思考」「ミニマムライフコスト」「AI・便利ツール」「ミニマルなモノ」の5つです。
「小さな習慣」は「暮らしを整える」に、「デジタル整理」は「AI・便利ツール」に含めています。「ミニマル思考」では書籍などを通じたミニマルな考え方を扱います。
各カテゴリーに入門記事を1本ずつ掲載しています。今回の5本はCodexが作成したオリジナルの入門記事です。実体験や特定商品のレビューとして作成したものではありません。投稿管理画面はなく、HTMLを直接編集します。

記事末尾には関連記事と更新情報へのリンクを用意しています。SNSのInstagram・YouTube・note・LINEは未開設のため「準備中」で、クリックできません。開設後は該当する`span.social-link`を実際のプロフィールURLを持つ`a.social-link`に変え、`aria-disabled`と「準備中」を外します。

RSSには記事5本の情報を収録しています。公開後、RSSリーダーにフィードURLを登録すると更新を購読できます。メール登録・購読者管理は実装していません。

Google アナリティクス 4 の測定IDは `analytics.js` に設定しています。閲覧者が「計測を許可する」を選ぶまでGoogleタグは読み込まず、許可後も実際の公開ホスト `minimalifehack.github.io` でだけ読み込みます。選択はブラウザー内に保存され、フッターの「アクセス解析の設定」から変更できます。ローカルプレビューでは計測しません。公開後は同意した状態でサイトを開き、Google アナリティクスのリアルタイムレポートで受信を確認します。

reCAPTCHAは現在設置していません。お問い合わせは現在準備中です。公開後は外部のGoogleフォームを利用します。将来フォームを作る際は、送信先のサーバーでトークンを検証し、秘密鍵を公開ファイルに入れない構成で追加します。

## 記事の追加・修正

1. `EDITORIAL.md`の該当カテゴリーの方針に沿って原稿を作成・確認する。
2. `articles/`の既存HTMLをひな形にし、タイトル、説明、本文、目次、カテゴリー、関連記事を更新する。公開日を入れる場合は実際の公開日を使う。
3. canonical・OGのURL・コピー対象URLを新しい記事URLに変更する。
4. `index.html`の記事カードと`feed.xml`、`sitemap.xml`に追加する。RSSのGUIDは公開後にむやみに変更せず、公開日を入れる場合はRSS形式にする。
5. ローカルでリンク・画像・スマートフォン表示を確認する。公開は別途承認後に行う。

コピー用URLとcanonicalは公開先を指します。新規記事を追加したときは、公開が反映されるまで新しいURLを案内しないでください。

## GitHubへの保存

対象リポジトリは `https://github.com/minimalifehack/minimalifehack`、公開先は `https://minimalifehack.github.io/minimalifehack/` です。
`index.html`はリポジトリの最上位に置く構成です。

変更を一括追加せず、公開に必要なファイルを選びます。個人用の`log.md`はGitへの追加方針が未決定のためステージしません。READMEや執筆ルールもGitHubに含めると公開情報になるため、内容を確認します。フォルダー全体を配信する方法に変更する場合は、ログ等が配信対象に混ざらない設定も必要です。

このリポジトリはGitHub Pagesの公開元が`main`ブランチのルートに設定されているため、`main`へのプッシュで公開サイトが更新されます。公開先・公開範囲を確認してからプッシュしてください。

## 元のZIPからの整理

元のZIP内の`dist/`の内容を最上位に配置しています。その後、ブログ掲載枠の追加、フッターロゴの差し替え、ミニマリズムを中心としたトップの再構成を行っています。
元のホスティングサービス専用の`.openai/hosting.json`は、この保存用セットには含めていません。
