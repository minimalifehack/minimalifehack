# minimalifehack

日常の小さな手間を減らし、好きなことに使える時間を増やすWebアプリの公開前ランディングページです。現在、最初のアプリは準備中で、名前・機能・公開日は未定です。このリポジトリにアプリ本体はまだ含まれません。

HTML・CSS・JavaScriptで構成され、パッケージのインストールやビルドは不要です。

## ファイル構成

- `index.html` — ランディングページ、目指す体験、公開状況、SNS
- `styles.css` — デザインとスマートフォン向けの表示設定
- `app.js` — メニューの開閉
- `analytics.js` — Google アナリティクスと閲覧者の同意設定
- `about.html` — 運営概要と開発方針
- `contact.html` — お問い合わせ窓口（Googleフォーム公開待ち）
- `privacy.html` — プライバシーポリシー
- `sitemap.xml` — 検索エンジン向けのページ一覧
- `assets/minimal-lifehack-logo.jpeg` — ヘッダーロゴ

ブログ掲載ページとRSSフィードはサイト方針の変更に伴い削除しました。過去の内容はGitの履歴から確認できます。未追跡の編集担当資料と作成中の原稿は公開対象に含めません。

## 手元で確認する

このフォルダーで次のコマンドを実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000` を開きます。終了はターミナルで `Ctrl+C` を押します。

## アプリ公開時に更新する箇所

1. アプリの名前、用途、機能、公開日、URLが決まったら、`index.html` の説明・公開状況・ボタンを実際の内容に変更する。
2. 実際のアプリ画面を掲載する場合は、コンセプトイメージと入れ替え、画像の説明も更新する。
3. 必要に応じて `sitemap.xml` と運営概要・プライバシーポリシーを更新する。
4. ローカルでリンク、画像、メニュー、スマートフォン表示を確認する。

トップのビジュアルは構想を示す図で、実際のアプリ画面ではありません。公開前のボタンは公開状況欄と既存のLINEアカウントに案内します。Instagram・YouTube・LINEは運営アカウントへのリンクです。noteは準備中で、クリックできません。

Google アナリティクスは閲覧者が許可した場合のみ、公開ホスト `minimalifehack.github.io` で読み込みます。選択はブラウザー内に保存され、フッターから変更できます。ローカルプレビューでは計測しません。reCAPTCHAは未設置です。お問い合わせ窓口は準備中で、受付開始後にGoogleフォームを利用する予定です。
